# Security & Bug Testing

## Test Case 1: Real Photo
- **Description**: Upload a standard, genuine photograph taken by a camera or smartphone.
- **Expected**: Likely Authentic
- **Result**: Passed. The system extracts EXIF metadata and standard resolution, scoring it low for AI probability.

## Test Case 2: AI Image
- **Description**: Upload an image generated by tools like Midjourney or Stable Diffusion.
- **Expected**: Likely AI Generated
- **Result**: Passed. The system flags known AI resolution patterns, detects anomalies in metadata, and triggers the AI warning.

## Test Case 3: Corrupted Image
- **Description**: Upload `abc.jpg` (but the file is broken).
- **Expected**: Error: Invalid Image File
- **Result**: Passed. The system intercepts the loading failure where the dimensions are zero and shows the appropriate error toast.

## Test Case 4: Wrong File Type
- **Description**: Upload a disallowed file, such as `virus.exe`.
- **Expected**: Only JPG, PNG, WEBP Allowed
- **Result**: Passed. The `accept="image/*"` attribute and internal `type.startsWith('image/')` check block the file and display the correct error toast.

## Test Case 5: Large File
- **Description**: Upload a 50MB image.
- **Expected**: File Too Large
- **Result**: Passed. The file size check catches the oversize condition and correctly blocks the upload with the "File Too Large" toast.
